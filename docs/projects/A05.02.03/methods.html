Forecasting the Yield Curve: Econometric Models versus Machine Learning

Does machine learning improve multi-horizon US yield-curve forecasts relative to random walk, autoregressive factors and dynamic Nelson-Siegel, after honest temporal validation?

Theory & methods

Purpose. Understand the theoretical restrictions and plan an independent implementation. This note supplies derivations and conventions, not solved research results.

Temporal indexing

Predict yt+h(τ)y_{t+h}(\tau), not the yield of a bond whose remaining maturity is τ−h\tau-h. For a forecast formed at tt, a training example originating at ss is eligible only if s+h≤ts+h\le t and its target is available. Scale features using training data; fit decay, lag choices and tuning only in training/validation. Use expanding refits with a predetermined schedule.

Comparable losses

Compute maturity-level errors in bp and aggregate with declared weights. For each horizon and model, report the same forecast origins, paired loss differences and serial-dependence-aware uncertainty. A negative ROOS2R^2_{\mathrm{OOS}} is possible. Prediction of a constant-maturity yield does not itself measure a tradable excess return.

Research checks

Implement a strong DNS baseline independently before ML. Lock temporal validation and data features, log all tuning choices and missing outcomes, and never select the final model using the final test loss.
