Research plan | A01.03.02

Study design and independent work

Retain the minimum 20 dated predictors and original minimum coverage; distinguish a permitted two-window subset from a three-window design. Log every date source and exclusion; do not equate journal publication with first dissemination or the OSAP migration with verified access.

Required tasks

  1. Build dated provenance table and document exclusions; freeze signed return series.

  2. Plot anomaly-level mean returns in the three periods, equal-weighted across signals.

  3. Estimate panel with anomaly effects, then calendar effects on common-support sample.

  4. Compare raw and factor-adjusted differences; common time block bootstrap with anomaly sensitivity and multiple-test adjustment for individual signals.

  5. Test fixed windows, publication-date lags and placebo dates chosen ex ante; distinguish short pre-publication periods.

Required exhibits

Date registry with original sources; sample attrition table; paired mean/alpha changes; event-time plots and uncertainty.

Robustness

No invented sample dates; avoid double-counting renamed signals, unbalanced composition or comparing disjoint anomaly sets. OSAP returns are reconstructed, not historical real-time published portfolios; publication effect is descriptive association.

Minimum viable thesis

At least 20 dated predictors, three-window or clearly labeled two-window subset, paired aggregate inference and documented publication timing.

Optional extension

Compare decay across independently coded liquidity or implementation difficulty groups; include working-paper release dates if documented.

Prerequisites

Panel econometrics, factor pricing, data cleaning, Python.

Thesis outline

  1. Anomaly discovery and decay;

  2. Event-time design;

  3. Metadata audit;

  4. Return and alpha comparisons;

  5. Identification limits.

Milestones

W1-3: literature and dates; W4-6: OSAP merge and eligibility; W7-9: panel analysis; W10-12: robustness; W13-16: write and archive.

At each meeting submit your independent code, parameter/input ledger, results and unresolved issues. Document failures and null findings.
