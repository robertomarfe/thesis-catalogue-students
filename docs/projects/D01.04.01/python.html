Setup check

Forward and strike conventions; no jump-model pricer.

import numpy as np
spot, rate, dividend_yield, maturity = 80., .03, .01, .5
forward = spot*np.exp((rate-dividend_yield)*maturity)
k = np.array([-.1,0.,.1]); strike = forward*np.exp(k)
assert np.allclose(np.log(strike/forward),k)
print('Setup check passed.')
