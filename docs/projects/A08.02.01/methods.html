Focused methods / A08.02.01

1. Gaussian updating

Let NN be the number of assets and JJ the number of views. PP is J×NJ\times N; QQ is J×1J\times1. With positive definite Σ,Ω\Sigma,\Omega and τ>0\tau>0, write the posterior precision and mean as

H=(τΣ)−1+P⊤Ω−1P,H=(\tau\Sigma)^{-1}+P^\top\Omega^{-1}P, μBL=H−1{(τΣ)−1π+P⊤Ω−1Q}.\mu_{BL}=H^{-1}\{(\tau\Sigma)^{-1}\pi+P^\top\Omega^{-1}Q\}.

Use linear solves rather than explicit matrix inversion in numerical code. The conditional covariance of the unknown mean is H−1H^{-1}; it is not the return covariance used in the baseline allocation. With zero view innovation the mean is unchanged.

2. Distinct sensitivity experiments

If Ω=cτD\Omega=c\tau D, D=diag(PΣP⊤)D=\operatorname{diag}(P\Sigma P^\top), then

μBL=π+ΣP⊤(PΣP⊤+cD)−1(Q−Pπ).\mu_{BL}=\pi+\Sigma P^\top(P\Sigma P^\top+cD)^{-1}(Q-P\pi).

Changing τ\tau with cc fixed cannot change this mean. Hold Ω=cτrefD\Omega=c\tau_{ref}D fixed, with τref=0.05\tau_{ref}=0.05, for the separate prior-uncertainty experiment. Do not treat that sensitivity as structural parameter identification.

3. Allocation and timing

Given an expected excess-return vector μ̂t\widehat\mu_t, choose

maxw≥0,𝟏⊤w=1w⊤μ̂t−γp2w⊤Σtw.\max_{w\geq0,\ \mathbf1^\top w=1}\ w^\top\widehat\mu_t-\tfrac{\gamma_p}{2}w^\top\Sigma_t w.

Here γp\gamma_p is portfolio risk aversion, distinct from the prior scaling δ\delta. Estimate all inputs from trailing matured observations. Before trading, drift the previous weights by realized asset returns and renormalize; compute turnover using the stated full- or half-turnover convention consistently with costs. Apply costs to the same portfolio capital ledger.
