**Reading focus:** Decomposition of matched-maturity nominal and real yield responses, not equity event regressions.

Nominal-minus-real yield changes represent changes in inflation compensation, not pure expected inflation (risk/liquidity premia and TIPS measurement matter). Identical event rows, regressor and response windows are necessary for slope additivity. Availability of intraday TIPS columns is not evidence of common event coverage. Never combine daily real changes with intraday nominal changes.
