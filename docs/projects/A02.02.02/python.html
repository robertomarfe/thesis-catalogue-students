Goal

Financial-conditions indices aggregate many signals and may describe risk-bearing capacity. But revisions and asynchronous release dates can manufacture apparent predictive content. The empirical contribution is a transparent availability-aware comparison, not a causal claim about monetary policy.

Research question: Do financial-conditions indices provide incremental out-of-sample information about aggregate equity excess returns beyond standard valuation predictors?

Student-owned research

Assert availability timestamp <= origin for every observation. Perturb all post-origin NFCI observations and ensure features do not change. Check holidays, missing weeks, release lag and common sample. Flag revised values.

  1. Audit index vintage, weekly observation/release dates, levels versus changes and return units.

  2. Estimate nested specifications; report HAC intervals, persistence and sample stability.

  3. Produce expanding-window one-step forecasts and common-date OOS R2, RMSE and forecast differences.

  4. Compare Clark-West for nested linear models and common-date bootstrap; interpret finite-sample uncertainty.

  5. Repeat with ANFCI, a 120-month rolling window and quarterly returns with appropriate overlapping inference; quantify effect of release lag.

Minimum viable thesis: NFCI and valuation predictors, historical mean benchmark, one chronological forecast test, timing audit, coefficient uncertainty and sensitivity to lags. Null results acceptable.

Record assumptions, independent checks, uncertainty and limitations in a separate research notebook. No core solver or research output is supplied.
