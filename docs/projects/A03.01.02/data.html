Construction and timing

Use identical quarterly inputs as A03.01.01; estimate AR(1) of g on contiguous quarterly runs only (no row shift across gaps). For stationary g use conditional mean mu+phi(g_t-mu) and residual SD; annual log safe rate=4log_safe. Analytic stationary SD of the annualized conditional rate is 4gammaabs(phi)sigma_g, with sigma_g innovation SD/sqrt(1-phi^2). Compare ex post rolling real bill log return proxy, not risk-free asset. Solve annual beta frontier via quarterly log rate mean, flag beta>=1. Refit model inside paired block bootstrap with gaps respected.
