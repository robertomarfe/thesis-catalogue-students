Stochastic Volatility versus Jump Risk: Explaining the Implied Volatility Skew

Can Heston and Merton models fit the same noisy synthetic vanilla quotes, and which maturity and strike diagnostics discriminate between the two mechanisms?

Discriminating tests

Let ii index option contracts with the same forward conventions. Define a common calibration loss ∑i∈𝒯[(Ci(ϑ)−Ciobs)/si]2\sum_{i\in\mathcal T}[(C_i(\vartheta)-C_i^{obs})/s_i]^2, with sis_i predeclared vega or noise scales bounded away from zero. Match approximate ATM variance term structures on training contracts and assess the remaining shape. Freeze training maturities and alternating strikes before fitting either model. Compare out-of-sample short wings and long-maturity shape on the same contracts; summarize uncertainty across noise draws and multistart dispersion. Neither model nests the other in general. An indistinguishable result is informative: it limits what the selected vanilla quotes identify.

Research checks

Generate a separate Heston and Merton truth panel. Use the same objective, bounds policy, numerical precision and untouched test grid across fitted models; report model-dependent failures and do not select short maturities after inspecting errors.
