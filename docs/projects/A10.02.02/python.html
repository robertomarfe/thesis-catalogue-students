Goal

Pooling portfolios can improve effective training information, but observations in a given month share shocks. Random row splits leak common time information, and a large network may mistake cross-sectional dependence for independent evidence.

Research question: Can a deliberately small neural network improve next-month portfolio return forecasts over linear models under date-blocked validation?

Setup check

Check that a toy panel keeps all assets of a date in the same partition. This artificial example does not validate the full research design or actual data.

dates=[1,1,2,2,3,3]; fold=["train" if d<3 else "test" for d in dates]
assert all(len({f for x,f in zip(dates,fold) if x==d})==1 for d in set(dates))
print('Setup check passed.')

Student-owned research

Assert no date appears on both sides of a fold; same test rows across models; labels mature before fitting; feature scaler learned on training only; check asset-specific mean benchmark and date-level averaging.

  1. Simulate panel with linear/nonlinear known signal and common date shocks; verify pipeline and leakage test.

  2. Build aligned features and targets, keep all portfolios of a date in same split, scale only training data.

  3. Fit models on identical training information, tune small grid and freeze protocol.

  4. Evaluate pooled and per-portfolio OOS R2 against expanding historical mean; paired date-block loss differences and seed dispersion.

  5. Optional long-short forecast-ranked portfolios on lagged weights, report gross returns and turnover; no stock-level claim.

Minimum viable thesis: French panel, same features for ridge/MLP, one locked chronological test and uncertainty across dates/seeds. Distinct from aggregate tree-based A10.02.01.

Record assumptions, independent checks, uncertainty and limitations in a separate research notebook. No core solver or research output is supplied.
