Purpose. Understand the theoretical restrictions and plan an independent implementation. This note supplies derivations and conventions, not solved research results.

Information and target maturation

At monthly origin tt, use the lagged credit and rate predictors. Treasury slope zt=yt10y−yt3mz_t=y_t^{10y}-y_t^{3m} is measured in percentage points with different quotation bases acknowledged. For a training origin ss, the 12-month target is available only after s+12≤ts+12\le t and the required recession information is known. Preserve missing calendar months. NBER retrospective dates and revised model-generated EBP prevent a real-time claim.

Forecast comparison

A logit assigns pt=(1+exp[−a−b⊤xt])−1p_t=(1+\exp[-a-b^\top x_t])^{-1}. Compare base rate, Treasury-only and augmented models with identical matured labels and evaluation origins. Brier loss is (Yt−pt)2(Y_t-p_t)^2; log loss is −[Ytlogpt+(1−Yt)log(1−pt)]-[Y_t\log p_t+(1-Y_t)\log(1-p_t)]. Use a declared numerical rule for extreme probabilities and report separation failures and episode counts. Overlapping labels create serial dependence; use block or episode-based sensitivity. Do not use the Fed-published recession probability as an input.

Research checks

Validate the actual file columns, release metadata, units and common coverage before estimation. Preserve pseudo-OOS wording and the planned ridge sensitivity if separation occurs. No inference based solely on a convenient AUC or retrospective fit.
