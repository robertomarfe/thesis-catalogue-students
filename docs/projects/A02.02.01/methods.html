Identification and implementation

For a genuinely nested squared-error comparison, let f0,f1f_0,f_1 be restricted and unrestricted forecasts. The Clark–West adjusted difference is e02−e12+(f0−f1)2e_0^2-e_1^2+(f_0-f_1)^2. Report unadjusted paired loss as the economic forecast comparison. The adjustment is not a generic test for nonnested competitors.

Research checks

First three forecasts recomputed by hand; no forward fill from later observations; exact common evaluation origin list; risk-free and yield units checked separately. Negative OOS R2 retained.
